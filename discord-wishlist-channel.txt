bunnie — 1/13/26, 8:12 AM
Forwarded
"full on" with a CPU running at 700MHz, an OLED display, external RAM, TRNG, etc. - about 40mA
wfi sleep - CPU is wakeable on an interrupt, no memory lost, recover in "milliseconds" timescale - around 12-14mA. Heavily temperature dependent - most of the power is leakage in the SRAM array. Reducing VDDCPU can get you even lower power numbers, I picked the rated 0.7V for the VDD core but I suspect you can undervolt and not lose memory and reduce that even further
deep sleep - RTC only running, backup registers preserved, key press interrupt wakeable - but nothing else on, SRAM array powered down, peripherals powered down - < 1mA, for the setup I had, 1mA is about the noise floor.
